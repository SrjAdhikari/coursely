# Coursely

Udemy-style LMS — TypeScript MERN. See `docs/` (`00-index` → `07-plan`) for the design and
`docs/superpowers/plans/` for the implementation plan.

Built as the submission for the **VeoLMS Core Team Selection Challenge**.

## Packages

- `server/` — Express 5 + TS API
- `client/` — React 19 + Vite SPA

## Develop

```bash
# API
cd server && npm install && npm run dev

# Web (separate terminal)
cd client && npm install && npm run dev
```
